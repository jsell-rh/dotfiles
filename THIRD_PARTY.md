Parts of the Hyprland, Rofi, Wlogout, Alacritty, and helper configuration came
from the local ML4W 1.0.1 files. Original author notices remain in those files.
The upstream project is [ML4W](https://github.com/mylinuxforwork/dotfiles).

The SwayNC configuration and style were copied from the installed Fedora
SwayNotificationCenter 0.12.6 package. Its license is included in
`licenses/SwayNotificationCenter-COPYING`.

The Ashell configuration is from the existing local setup. The upstream
project is [Ashell](https://github.com/MalpenZibo/ashell).

The `hyprshot` helper, emoji data, and two wallpaper files were copied from
the existing local setup. Their exact source revisions and asset permissions
have not been established. Keep these provenance questions in the publication
review. No new license is assigned to these files by this migration.
